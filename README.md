# ACLE-Net: Deep Learning for HCI & Data Visualization Evaluation

## Cara Menjalankan Proyek

1. **Install Dependensi:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Training Model:**
   ```bash
   python train.py
   ```

3. **Evaluasi Model:**
   ```bash
   python evaluate.py
   ```

4. **Inference / Prediksi Gambar Antarmuka Baru:**
   ```bash
   python predict.py
   ```
